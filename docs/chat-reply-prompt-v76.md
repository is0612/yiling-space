# 对话提示词 v76：群聊消息与作者身份

这次更新只改群聊提示词和发送给模型的数据。角色预设、群聊放行策略和私聊记忆范围沿用原有设置。[v75 存档](chat-reply-prompt-v75.md)保留上一版的提示词全文；当前源码是[主回复模板](../server/utils/chat-reply.ts)和[语境助手](../server/utils/context-assistant.ts)。

| 数据 | 用途 |
| --- | --- |
| `transcript` | 本轮逐条消息，带说话人、主人标记和 @ 对象。有这一栏时省略拼接版正文。 |
| `currentMessage` | 没有逐条消息时提供正文。代码内部仍可用拼接文本做检索。 |
| `recentMessages` | 近期对话。主回复已看到本轮某条消息时，不在这里重发。 |
| `groupBackground` | 补充较早的原始证据。只补前两栏没发送过的消息 ID；有可信作者标记时一并保留。 |

去重按消息 ID；两人发了同样的文字，仍是两条消息。历史里的 `role: ASSISTANT` 表示角色自己说的话，`isOwner: true` 表示可信的主人身份。只有昵称或缺少标记时，不能推断为主人。语境助手机制仍保留正文预算，预算紧时优先给本轮较新的逐条消息留正文。

指代先看可信身份、实际 @ 对象和原话，再用成员归属表辅助。以下都是虚构例子：

- 已确认的主人说「@你，我的鱼，你怎么看」：可以把「我的鱼」理解为当前角色。
- 群友说「我的鱼今天学会唱歌了」，上下文明说是别的角色：不要冒认。
- 一条消息同时 @ 角色和群友：根据原话判断哪一部分是在问角色。只 @ 别人的话仍不能当作直接问角色。

回归测试检查发给模型的数据和规则，包括同一条群消息不重复、长正文不能借拼接版绕过逐条上限、旧证据保留作者、混合 @ 不走「只 @ 别人」的规则。测试使用模拟响应，实际接话表现仍需观察。
