# 自我认知：首版实施边界

本阶段承接反思闭环提交 `2232683899e1`。只推进自我认知，不开发状态系统或桌面端。

## 最小完整能力

实现一个按需、只读的认知整合消费者，复用现有聊天模型与领域数据，不增加独立常驻助手、事实总表或人格数值。首版不持久化模型生成的自我描述；来源更新、停用和修订后下次读取当前版本，避免另一份自我描述长期漂移。

仅在明确询问角色身份、性格、对自己的认识或成长变化时触发。普通闲聊不增加跨领域查询。入口继续负责可信角色、会话和可读范围；整合器不能接受模型或浏览器提供的 scope 列表扩大权限。

## 视图分层

- 基础：当前名字等角色明确配置的身份线索，引用角色记录。不能把 basePrompt 整段复制成可公开资料，也不能由普通经历自动覆盖它。
- 外观：头像、形象属于表现形式，与“自己是谁”分开标明；不能由外观词推导人格或物种认同。图片 URL、内部路径及图像字节不传入认知提示词，仅标记有已配置图片；简短文字或表情仅作为外观线索。
- 动态证据：已确认偏好、表达习惯、进行中目标、已审核关系、相关经历和记忆、有效知识及已采纳成长建议。每项保留领域、记录引用、当前版本或更新时间与适用范围。
- 暂时理解：由本轮聊天模型基于证据表达，明确证据不足、变化与冲突，不把候选或肯定语气当成事实；不会自动写入长期领域。

## 安全与生命周期

群聊只允许全局来源；私聊与 Web 继续遵循各自可信身份的可读范围。原会话经验及其派生表达只能在原会话使用。未审核关系、PENDING 偏好或成长候选不可作为确认认知。已采纳反思只是来源支持的解释，不能冒充原始事实或替代角色配置。

不要求各种资料都存在。明确返回本轮未提供的领域，空数据不拼造自我经历。资料有时效、场景或不确定性时保留这些语义，不将用户偏好错归为角色偏好。知识表示学过什么，不等于性格；关系表示已审核定位，不等于模型可自行决定关系。

## 计划验证

- 普通消息不触发、明确自我认知问题触发。
- 身份与外观分离；来源及版本保留，未知字段与超额内容不入视图。
- 角色隔离、群聊/私聊边界、原会话限制，候选与失效来源排除。
- 来源编辑、停用后下一轮立即更新；冲突不静默合并，模型推断不自动落库。
- 既有聊天与私聊回归、隔离数据库、真实合成模型与实际聊天入口验收。

## 第二批自然问法与能力证据修复（v75，2026-11-18）

v74 自然复测暴露了助词漏匹配和早期记录不可读的无依据自述。当前有无助词的经历 / 例子问法均纳入有界承接；只在授权范围查询已经成功后，才给出 `memoryRead=authorized_scoped_read_succeeded`，而 `historyCompleteness=not_established` 保持未核实。该字段是本轮窄范围读取事实，不是全量访问保证，也不属于情绪状态或永久能力设定。

原会话结构化经验有 `subject=current_character_response` 标记，表示对本角色回复的反馈，不代表永久人格已改变。普通记忆不凭角色归属自动获得该标签，模型仍需理解文中主体；用户告知的软件进度与另一角色报告分别保留其来源与时间，不能混为自己的完成事项。

纯函数语形组合、两种追问的实际 Web HTTP、隔离来源与权限回归、完整类型、定向 Lint、独立生产构建已通过。合成真实模型使用了中性问法、旧错误助手历史、本人反馈和他人报告的混合对照，观察到主要问题改善；仍有概括性措辞偏强，待自然复测，不把单次模型回答称为全面解决。匿名详情见 [实际使用记录](real-use-acceptance.md#第二批自然私聊复核与修复v75)。

## 首批自然使用问题修复（v74，2026-11-18）

匿名问题与原样本状态见 [实际使用记录](real-use-acceptance.md)。原始私聊正文未加入仓库，也未修改真实领域记录。

- 省略主语的变化追问及紧邻的来源追问，仅在同一私聊上一条 ASSISTANT 回复带服务端认知标记、间隔不超过 15 分钟时承接；普通回复插入、换会话、过期或群聊均不继承。复用最近消息，不新增会话状态表或模型分类调用。
- 外观标记为主人可修订；视图明确不提供已观测运行事件或当前能力评估。历史查询失败不能证明现在没有能力，无依据的版本变化描述应撤回猜测，不能补造消息来源。
- 长反思为观察、暂时推断、建议分别保留片段，避免观察挤掉纠正方向；结构化经验优先提供用户纠正和下次判断，而不是重播旧错误台词。所有截断显式标记。
- 记忆可以记录具体经历，experience 领域只指短期互动反馈卡。未选入领域使用准确的 `interaction_feedback_cards` 标签，并提供本轮选入计数；没有反馈卡不等于没有经历，缺少前后对比不能编造近期变化。

纯函数、实际 Web handler 和隔离数据库回归覆盖有界承接、换话题退出、未授权范围、纠正投影与长片段边界；完整 TypeScript、相关聊天 / 语境 / 历史 / 成长回归、定向 Lint 和独立生产构建通过。四个合成真实模型 HTTP 场景已对照：追问实际拿到视图，旧失败保留为历史报告，缺少对比时不编造变化，承认外观可以修改，来源追问时撤回没有依据的重启猜测。此前的有界视图不等于全库的限制仍适用；合成复验通过不替代用户自然重测。

## 首版完成与验收（v73，2026-11-18）

已实现只读领域适配器、有限证据视图和 Web / QQ 的按需接入，提示词版本递增到 v73。明确问题才增加跨领域读取，不新增模型调用或业务数据表。本轮提供给模型的来源领域、记录 ID、版本、更新时间和范围会记录到原回复消息的 `providedSelfUnderstandingSources`，不复制私人证据正文，也不宣称模型实际采用了每条来源；首版未提供独立认知管理页面。

纯逻辑视图与提示词测试通过，覆盖外观分离、已采纳解释与短期经验的不同语义、候选排除、预算、无跨轮缓存及普通聊天不携带该视图。一次性 PostgreSQL 测试通过，覆盖角色、私聊范围、原会话与群聊隔离、全局反思不能借用私人来源、来源失效与名字修订后即时更新。知识与记忆保持 active_record 语义及原始 confidence，不能把有效来源误认成人工确认。notProvided 仅表示本轮有限视图未选入，不代表整个领域不存在或角色没有经历；updatedAt 是记录更新时刻，不当作经历发生时间。

真实 Web HTTP handler 回归通过：匿名与跨角色访问被拒绝，普通问题不携带认知视图，明确自我问题使用服务端当前名字与正式偏好，客户端伪造视图被忽略；模型调用仍每次一次，回复保存有限来源引用而不保存证据正文，也没有新增偏好。幂等重放不重复生成。

真实 `deepseek-flash` 与 Chromium 验收使用临时角色和合成资料：模型结合确认偏好及学过的知识回答，承认证据不足，并把外观与身份分开；浏览器实际输入、发送并展示新回复，数据库随后核对本轮来源引用，PENDING 偏好未被提供，未产生新正式成长。另通过实际渠道管道验证私聊允许当前身份私人记忆，GROUP_MESSAGE 加完整群上下文时视图及回复均不包含那条私人记忆。渠道回执仅留内存，未向真实 QQ 发消息。

完整 TypeScript、认知纯测试与提示词测试、隔离协作及 Web 数据库回归、现有聊天、语境、私人记忆、主人历史、偏好、表达和目标回归，以及定向 Lint、独立输出目录生产构建通过。此前 Windows 生产包启动限制未重新验证，不能将构建通过说成该问题已修好。首版没有持久化“自我认知事实”或独立审核管理页面，新的自我解释只停留在对话中；不保证所有自然问法和模型推断都正确，不把单次回复等同普遍的行为因果证明。
