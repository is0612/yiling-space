# 短期互动经验卡

互动经验由角色从对话反馈中自主形成，用户不需要选消息或逐条审核。入口 `/growth/memory/interaction-experiences` 用于查看经验和依据、纠正及停用；与角色级稳定表达习惯分开。

## 自动收尾

常驻 Worker 按代码规则识别私聊闲置 30 分钟或消息段达到阈值，读取本会话尚未处理的消息，由模型判断回应效果。每段有界处理，来源白名单、逐字反馈引用、消息顺序与范围校验通过后保存 ACTIVE；没有合格反馈可返回空结果。沉默、换话题、普通附和不代表回应有效或失败，隐私、保密与稳定底线不写成可衰减经验，也不自动修改人设或关系。

自动处理由独立的「自动形成互动经验」开关控制，不随意打开自动忆泡或阶段总结。部署迁移写入持久化启用锚点，只处理其后的新对话，避免升级自动重扫历史。每会话保存进度、任务状态、租约和重试时间；成功包括空结果时推进游标，失败不推进，失去租约的旧执行者不能提交。既有同证据经验不重复创建，也不将人工停用或驳回的记录重新启用。

## 理解与应对经验

回顾不只评价语句好不好听，还覆盖理解错误（UNDERSTANDING）、对象指代（REFERENCE）、场合判断（SITUATION）、应对策略（STRATEGY）和表达（EXPRESSION）。`learning` 保存当时情境 `situation`、原误解 `misunderstanding`、有反馈支持的纠正 `correction` 与下次判断 `nextJudgment`；正面反馈可没有原误解。旧卡的空结构保持兼容，不自动编造历史纠正。

模型会看到本会话中回复之前的原用户请求及有限前文，不能只凭助手回复猜用户意图；所引用消息仍按白名单和事务证据校验。召回结合当前语句和最多四条近期用户语境，以有界情境类别线索帮助跨措辞匹配，不为每次召回新增模型调用。不相关场景不因旧经验存在而强行注入。经验是可修正的记忆，不是永久命令，当前明确纠正优先。

## 长期互动指导（跨会话）

已授权私聊里的理解、指代、场合与应对纠错，经后台分析可形成 `CharacterInteractionGuidance` 候选：类型为 UNDERSTANDING / REFERENCE / SITUATION / STRATEGY，保存抽象指导、适用场景、聊天范围（ALL / GROUP / PRIVATE）和来源引用。原经验卡仍在原私聊；正式指导不复制私人原文、账号或原始原因，也不进入表达习惯、偏好或社交关系表。

候选默认 PENDING，在互动经验页的独立「长期指导」区块由角色主人核对正文、场景、范围和原因后采纳，可编辑、驳回、停用并查看修订历史。首次采纳锁定并重验来源指纹与当前教育授权；采纳后由本领域独立版本管理，原经验清理或衰减不删除指导，撤权不撤销已采纳规则，停用立即停止召回。所有操作按角色主人隔离，来源引用不等于私聊读取权限。

群聊与私聊由真实入口传入聊天范围，仅召回生效且场景匹配的指导，最多三条、预算1200字符，原私聊经验卡不进入群聊。提示词把指导标为「已审核但可能不适用」的抽象参考：当前语境、明确纠正、身份、隐私与渠道规则优先，不能据此声称此群发生过私人事件，也不能透露来源。自然场景匹配是有限关键词相关性，不承诺完整语义识别。

明确长期教育可凭单条证据提候选；重复型需要不同反馈与跨日条件，不能把无关纠正相加。只引用旧证据、证据不足或领域不匹配的建议丢弃不保存，不让整批失败；失败状态只记录白名单错误码。回归入口为 `yarn test:interaction-guidance`、`yarn test:interaction-guidance-isolated`；后者使用一次性数据库和 mock 模型，真实语义质量仍需人工审核与自然对话观察。

## 使用与管理

经验只在原网页或 QQ 私聊会话及原记忆范围使用，不将私人经验传到群聊。按当前语句匹配场景，相关度乘七天半衰期，低于 0.08 不注入，每轮最多三条。衰减不删除记录，编辑不重置创建时间。列表显示时间衰减权重，实际召回还受场景相关度影响。

「只在原会话使用」指的是这些经验卡本身；不要把它与下面经主人审核的长期指导混为一谈。

用户可查看反馈依据、纠正经验内容、停用不适合的经验。旧版人工提炼 POST 及 PENDING 审核保留兼容，不再是主路径。所有变更保留审计和乐观版本校验。删除会话时临时经验及处理进度随会话删除；删除原文不会级联删除已生效卡片。列表最多 100 条，暂不提供历史分页或角色卡导出。

## 反思与语言系统

Worker 把同一私聊会话中多条独立、跨反馈真实发生日期的经验作为一批，引用经验 ID、版本指纹和原范围排入既有反思队列。不会每张卡都额外调用一次反思，也不把私人经验混入原全局反思。观察、推断和建议分别保存，后续审核时复核来源。

理解、指代、场合和应对纠错留作经验与反思；只有多条 EXPRESSION 证据支持的稳定表达变化，才生成原会话的 PENDING 语言习惯。它不自动修改人设，仍须确认才成为稳定表达倾向。派生习惯激活和召回都复核源经验是否 ACTIVE、版本和内容是否一致；源经验纠正或停用后，旧派生习惯不再注入。群聊及其他私聊不读取它。

全局偏好、目标及通用语言来源不能选择这些私聊反思，角色卡导出和分享默认排除私聊派生反思与成长事件，不能通过导入去掉范围将它升级为全局。

当前排程每轮最多 10 个候选会话、300 条候选，单次反思最多 30 条经验，每个反馈发生日期最多选 15 条。极端情况下大量同日积压会延迟跨日反思；未做大规模会话压力测试。跨措辞召回采用确定性情境线索而非向量全语义，不能保证所有改写命中。

## 发布与验证

迁移为 `20261113090000_interaction_experiences` 与 `20261113100000_interaction_experience_automatic`；先备份并验证，再迁移和生成 Prisma Client，更新 Web 与 Worker。自动服务必须有常驻 Worker，打开网页本身不保证收尾执行。

模拟与隔离数据库回归验证进度、重试、租约、来源、自动生效、去重和范围隔离；真实模型是否准确理解回应效果仍需观察自然对话，不能用模拟断言代替语义质量评估。
