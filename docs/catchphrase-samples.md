# 梗语录示例库：两种人格的写法

> 这是**可以照抄的模板**，不是成品角色卡。所有台词为原创，不含任何第三方作品的角色名、设定或原文。
> 数据文件：`scripts/data/sample-cold-jokes.json`（47 条）｜`scripts/data/sample-stage-host.json`（53 条）
> 导入命令 `yarn catchphrases:import`，参数见 [§3](#3-怎么入库)。

梗语录（`character_catchphrases`）和普通提示词的区别只有一条：**每条都要带 `usage`**。模型的用法是"看时机原样说出来"，没有时机说明的台词，它一辈子不会说。

所以示例库的价值不在台词本身，而在**台词和时机怎么配**。下面两种人格覆盖了两个最主要的类型。

---

## 1. 示例 A：冷笑话型（靠谐音）

### 1.1 三拍结构

冷笑话不是单句俏皮话，是三拍：

```
提问（看似正经）→ 答案（硬谐音）→ 补刀（不好笑吗 / 你自己品）
```

- 第一拍负责骗人认真听，第二拍是全部笑点，第三拍负责把尴尬推上去。
- **台词写成一条消息说完**，因为梗语录一次只说一句、说完就结束。
- **谐音必须生硬**。越勉强越对——冷笑话的全部威力来自它讲不通。一个太顺的谐音不是冷笑话，是段子。

收尾句可以单独抽出来当梗用（这 5 条在库里是独立条目，也能挂在任何一条后面）：

> 你可以不笑，但你不能不冷。
> 笑点已经冻住了，等春天再笑吧。
> 我讲笑话从不失手，只会失温。
> 你可以说我不好笑，但不能说我不冷。
> 我不是在讲笑话，我在做天气预报：局部有霜。

### 1.2 造梗四步（照这个来，一分钟一条）

1. **挑字**：从角色的名字、称号、职业、经历里抠一个字。
2. **找同音**：拿这个字去撞日常词（梨 → 离 / 伞 → 散 / 姜 → 将）。
3. **造因果**：给同音词编一个"合理"的解释理由，理由越牵强越好。
4. **收一刀**：加一句「不好笑吗？」或者干脆什么都不加，等对方沉默。

反推演示：`梨` → `离` → 一梨两散 →「为什么卖梨的最怕分手？因为一「梨」就得两散。」

## 2. 示例 B：点评型（靠逻辑）

### 2.1 两种人格的区别

这两种"好笑"来自相反的地方，混在一起用会互相削：

| | 冷笑话型 | 点评型 |
|---|---|---|
| 笑点来源 | **谐音**，硬扭两个字 | **逻辑**，抓你话里的洞 |
| 结构 | 提问 → 谐音答案 → 补刀 | 你报价 → 它反问 → 你补设定 → 它加/砍价 |
| 姿态 | 讲完等你沉默 | 全程接话，永不冷场 |
| 权力关系 | 平级，谁都能走 | **它在定价，你在求它** |
| 口头习惯 | "不好笑吗" | 打分、砍价、"加价！" |

所以给点评型角色写梗，**不要写谐音梗**，要写"一句顶回去"的话。它的杀伤力在于：你越解释，它越有得问。

### 2.2 造句三规律（照这个能一直写下去）

1. **先复述，再拆**：「你说它稀有。稀有是因为没人要，还是因为没人有？」——复述你的词，然后把词拆成两个意思。
2. **只认它认得的证据**：「手感好？我摸不到。」——它只有耳朵，所以只在"说得好不好"上打分。
3. **价是评价的具象**：夸 = 加价，嫌 = 砍价，看不上 = "算赠品"。所有判断最后都落成一个数字。

```bash
yarn catchphrases:import --character <角色id或角色名>            # dry-run 看会加哪些
yarn catchphrases:import --character <角色id或角色名> --apply     # 真写

# 点评型
yarn catchphrases:import --character <角色id或角色名> --file scripts/data/sample-stage-host.json --apply

# 只导前 20 条先试试
yarn catchphrases:import --character <角色id或角色名> --apply --limit 20
```

- 按 `phrase` 去重：同一句导两次不会变成两条，重复执行只跳过。
- 已在库里的台词**不覆盖**你改过的 `usage` 和 `enabled`。
- 也可以手动加：`/characters/{id}/settings/catchphrases`，一条一条粘。五十多条手点会很累，脚本更合适。

**导完先别全开。** 提示词一次只装 15 条（`CATCHPHRASE_PROMPT_LIMIT`），挑选规则是"没用过的排最前 → 冷却中的垫底"。所以全开的效果是：头几天她连着冒新梗，之后靠 2 小时冷却轮转，一天能听见七八次不重样。想让"梗感"更稳定，建议只开 15–20 条，其余留着不放。

## 4. 一个容易踩的坑

梗语录的提示词只写**匹配时机**、不写频率（"偶尔说一句"会被模型当默认答案，结果一句不说）。所以 `usage` 写得越具体，命中率越高：

- ❌ 「聊天的时候说」→ 模型不知道什么时候算对上了
- ✅ 「有人抱怨、求助、求人办事时」→ 对上就能立刻用

凡是 `usage` 写成「聊 XX 时」的，都是靠话题词命中，属于较松的一档。如果你发现某条一直不说，通常是 `usage` 太笼统，改成"对方刚说完 XX 这个词"这种具体信号就行。

## 5. 换成你自己角色时

示例库是让你少走弯路的，不是让你直接用。改的时候按顺序来：

1. **先定笑点来源**：这个角色是靠谐音、靠逻辑、还是靠反差？选一条，别混。
2. **把 `usage` 场景换成她真实会遇到的**：群聊被 @、私聊说晚安、有人在群里吹牛——具体到这一步，命中率才准。
3. **数量控制在 20–30 条**：再多也不会全说出来，反而稀释冷却。
4. **台词长度压到一句**：梗语录的定位是一次说一句、说完结束，超过两行就不像人说话了。
