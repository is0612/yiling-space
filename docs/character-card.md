# 角色卡：导出、导入与删除

> 换电脑通常不需要搬整个数据库。角色卡带走的是「她是谁 + 她记得什么 + 她认识谁」，
> 账号、渠道 Token、任务队列和会话原文都留在原机器。
> 整库迁移见 [本地开发与数据迁移规范](local-development-and-data-migration.md)。

## 1. 导出

角色管理 → 选中角色 → 「更多」，两个入口：

| 入口 | 给谁用 | 区别 |
| --- | --- | --- |
| **导出角色（含朋友）** | 搬家自己用 | 朋友段里有别人的 QQ 号和「她怎么看他们」 |
| **导出（不含朋友，可分享）** | 发给别人 | 朋友整段不写进文件 |

## 2. 会带走什么

| 会带走 | 不带 |
| --- | --- |
| 人设、对话示例、称呼、别名 / 简介 / 头像配色 | API Key（导出的 JSON 里没有任何密钥字段）、渠道 Token |
| 长期记忆：角色全局 + **导出者自己的**私人记忆 | 其他站内用户的私人记忆 |
| 忆泡、梗语录、当前版本的阶段总结 | 会话原文、阶段总结的来源记录、任务队列、用量与审计 |
| 模型名 / Base URL / 温度 / Token 上限等少量参数 | 表情包图片（换机器后在「表情包」里从 QQ 收藏夹重新同步） |
| **她的朋友**（默认带）：昵称、平台账号、聊过几次、从哪认识、认识多久，以及她记得关于他们的 | 朋友的账号绑定（`status` / `linkedUserId`）—— 那是本站的验证结果，换人不该跟过去 |

## 3. 导入

角色管理页头「导入角色」→ 选文件 → 先看预检摘要（名称、记忆 / 忆泡 / 阶段总结 / 梗 / 朋友的条数）→ 确认导入。

- **总是新建**：同名只会在名称后加「副本」后缀，不覆盖、不合并到已有角色，原角色的一条记忆都不会被动到。
- 记忆与忆泡不带来源消息指针（原文没随包走），阶段总结导入后记为第 1 版。
- 朋友按 `(平台, 平台账号)` 认人：本机已有同一个 QQ 号就沿用那条身份，不会重复建，也不会改写它原来的验证绑定；0 次互动的关系（群里出现过但没被搭理的残留）不进包。

导入之后要做三件事：到「模型设置」重填 API Key，到「记忆设置」确认归档周期，到「表情包」重新同步。

## 4. 删除是彻底删，先导出再删

删除**没有回收站**。角色、会话与消息、记忆与忆泡、阶段总结、梗、她的朋友关系、表情包清单都会被清掉，`.data/stickers/<角色 id>/` 与 `.data/sticker-originals/<角色 id>/` 两个目录也会整目录删除。

审计日志保留（`characterId` 置空，同时会写一条 `character.deleted` 记下名字和删除量），token 账单保留。

所以想换电脑重建时，顺序是**先导出角色卡，再在新机器上导入，确认无误后回旧机器删**。反了就只能重养。

历史遗留的孤儿行和孤儿目录用 `yarn clean:character-orphans` 查看，加 `--apply` 清理。

## 5. 验证

```bash
yarn test:character-card      # 格式、密钥剥离、朋友段校验、非法输入拒绝
yarn test:character-card-db   # 范围隔离、朋友导入、身份复用、来源置空
yarn test:character-delete-db # 级联表、三张没有外键的表、表情包目录、审计留痕、账单保留
```
