## 2026-11-14 更新摘要

本轮补齐「私聊教育 → 跨场景可用」：教育资格、抽象候选、主人审核与生效范围。所有候选都需人工确认，模型输出不会直接改写人设、关系或渠道权限。

| 能力 | 当前实现 | 状态 |
| --- | --- | --- |
| 教育资格 | 好友档案新增「允许教育此角色」，默认关闭；仅角色主人可设，服务端校验 owner 并审计；不随关系升级、模型结论或角色卡导入变化 | ✅ |
| 表达习惯跨场景 | 已授权私聊的明确长期表达纠正或重复一致证据，生成待确认表达习惯；采纳后按适用范围用于群聊/私聊 | ✅ |
| 聊天范围限定 | 表达习惯与互动指导保存 ALL / GROUP / PRIVATE；服务端按真实入口筛选，正文里的「群聊」字样不能绕过 | ✅ |
| 理解与应对指导 | 理解、指代、场合、应对四类抽象指导独立管理，支持编辑、驳回、停用与版本历史 | ✅ |
| 长期指导使用 | 群聊/私聊按场景召回已生效指导，最多三条、1200 字符预算；不携带来源原文或账号 | ✅ |
| 渠道行为候选 | 主人审核后可关闭 QQ 被动群回复的 @ 提醒，正文/引用照常；不影响主动联系与公告 | ✅ |
| 教育分析可靠性 | 旧证据、证据不足、领域不匹配的单条建议丢弃但不整批失败；失败只记录白名单错误码 | ✅ |
| 私聊引用原文 | 私聊引用按消息 ID 回查并把该条原文单独传给模型；无引用不增加请求 | ✅ |
| 接续摘要不阻塞 | 回复只读现有摘要，后台更新；限时、关闭思考、失败不推进 | ✅ |

这些能力都经模拟模型与一次性数据库回归验证；真实模型对「这条要求是否长期、是否可跨场景、是否含私人信息」的判断仍需在自然对话中观察，不能把「候选已生成」当成「教育已生效」。规则细节见 [记忆系统](memory-system.md)、[互动经验](interaction-experiences.md)、[表达习惯](expression-habits.md) 与 [社交系统](social-relationship-system.md)。

## 0. 一句话·

一个多角色 AI 养成平台：**角色管设定与记忆，渠道只管收发**。角色在 QQ 群、QQ 私聊、B站 值班台、网页工作台四处活动，所有经历写进同一份分层记忆。

规模：**122 个接口 / 32 个页面文件 / 32 张表 / 40 个迁移 / 57 个服务端模块**。

## 14. 如果要对外讲，最能打的 10 个点

按「别人没有 / 有也不好讲」排序：

1. **8 天不是保留期** —— 周期只决定「多久复盘一次」，原始消息保留期是另一个开关。
2. **四层记忆各管一件事** —— 原文是证据，忆泡是事件，快照是结论，长期记忆是现状。
3. **重新生成不覆盖** —— 新版本 + 旧版可追溯 + 人工修正留审计。
4. **删除不抹历史** —— 删掉原始消息，历史快照里的文字仍在。
5. **忆泡不伪造精度** —— 只知道「下午」就记「下午」。
6. **群聊按话题不按人** —— 判断的是「这个话题现在要不要我」，不是「这个人我认不认识」。
7. **主动找人先判后说** —— 闸门是纯函数，一次 tick 判定成本为零；顺序把配置问题排在时间问题前面。
8. **语音尾巴补 0.7 秒静音** —— 不是音质问题，是 QQ 时长取整会切掉最后半句。
9. **日记允许 SKIP** —— 没内容就不写，不为了填满栏目硬编。
10. **watchdog 指向具体环节** —— 不只报「有异常」，而是排期 / Worker / 任务三者之一。
