# 成长数据真实消费者接入验收

本批只推进成长数据消费，不新增领域表、向量检索、反思流程、自我认知或状态系统。私聊和 Web 协作收尾已提交为 `5737f3f`。

## 现有消费者与边界

| 数据 | 实际读取器 | 聊天消费方式 | 生效边界 |
| --- | --- | --- | --- |
| 互动经验 | `readInteractionExperiences` | QQ 私聊与 Web 将匹配经验提供给主回复 | 当前角色、会话、记忆范围、ACTIVE，最多 3 条；不直接给群聊 |
| 偏好 | `loadPreferencesForPrompt` | 群聊、私聊与 Web 按问题匹配 | 仅 ACTIVE；已确认偏好独立于原来源保留；不是用户一说就写入 |
| 表达习惯 | `loadExpressionHabitsForPrompt` | 根据场景和查询选择表达规则 | ACTIVE，GROUP / PRIVATE / ALL；会话经验来源重新验证，不跨会话 |
| 目标 | `loadGoalsForPrompt` | 向回复提供匹配的进行中目标 | ACTIVE；PENDING、PAUSED 与其他状态不作为进行中目标 |
| 社交关系 | `listAcquaintances` 与 `readReviewedFriendRelationship` | 群聊、私聊和 Web 的熟人背景 | 只提供有限关系信息；未审核版本不当作关系事实，BLOCK 不进名册 |

入口分别为渠道 `pipeline.ts` 和 Web `chat.post.ts`。领域读取没有强制经过事件队列：当前行为需要最新数据时直接调用所属领域的只读服务，避免再造一份同步副本。事件中心已有真实消费者负责记忆来源校验、社交评估派发、忆泡转知识候选；本批不为了凑齐领域而新增事件。

## 本批验收

新增 `scripts/test-growth-consumers-db.ts`，通过 `test:assistant-collaboration-isolated` 使用随机命名的一次性 PostgreSQL 库。用同一组查询读取五类领域，再修改领域状态并重复查询，检查下一轮消费者是否读取最新事实：

- 已确认偏好、表达习惯、目标与本会话经验能被选入，待确认候选不能入模。
- 即使记忆范围相同，其他会话经验仍不返回；PRIVATE 表达规则不进 GROUP。
- 停用经验、偏好、表达习惯或暂停目标后，下次读取立即不再选入。
- 未审核关系不输出确定关系阶段；审核版本生效后返回新阶段与状态；屏蔽后不再进入熟人背景。

实际执行：`yarn test:assistant-collaboration-isolated` 已通过，全部 87 个迁移在空库应用成功，原有协作日志鉴权及来源白名单测试也保持通过，临时库已删除。该测试验证真实领域服务和数据库的消费行为，不使用付费模型。读取正确不等于模型一定采用，模型自报引用也不代表已证明因果。此前私聊 / Web 真实模型验收已证明部分知识与成长数据可以进入实际回复；本批已补齐消费者状态变化的数据库验证，定向 Lint、完整 TypeScript、隐私与差异格式检查均通过。本批未修改运行时业务逻辑，因此未重复生产构建；此前协作阶段的构建通过和 Windows 生产启动限制仍按原记录保留。五领域的读取接入与生命周期边界已验收，不等于新的反思闭环已经完成。
