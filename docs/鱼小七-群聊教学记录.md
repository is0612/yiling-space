## 2026-11-02 ~ 11-03：怎么「养」一条鱼

这两天她说得比较散，核心是「别手写规则，喂语料、烧时间」。

- **「丢群里啊」**（11-02 13:40）
  白止说他的鱼「这群她没说话，丢别的群里会自己说」，她给的答案就是把鱼丢进群里。
- **「越密集信息量越大越快」**（11-02 13:42）
  白止问「那就在这个群全开放？」，她这么答。意思是群聊的信息密度越高，学得越快。
- **「先烧token」**（11-02 13:59）
  Moming 问「如果我的鱼进来，你能也点拨一下她吗」，她先回这三个字。
- **「不烧个一周一个月的都没啥大进步」**（11-02 14:01）
  紧接着补的。她对「养鱼」的时间预期是周/月，不是调两下参数。
- **「是做摘要和分析，说明该接什么不该接，而不是手动拉什么频率」**（11-02 16:15）
  这句最像设计意见：判断该不该接，应该让模型做摘要和分析，不是人去手调接话频率。
- **「默认提示词没改过吧，我看到很多了」**（11-03 10:47）
  她看了一圈群里的鱼，判断很多还在用默认提示词。

## 2026-11-04 上午：接哪个模型、声音怎么练

### 1. 模型与容量：五条 + 一句拒绝（11:07）

鱼姐的狗贴了 `swarm` 文档，问她：每个 agent 分别该接哪个模型，只考虑国产。她回了两条：

> 「容量按p95算、P0留应急口、退回表加责任方、速率比用中位数，另查出口限流数字是否自洽。」
>
> 「模型不能推荐」

五条拆开：

| 原话 | 人话 |
|---|---|
| 容量按 p95 算 | 按高峰那 5% 的尾部估，不按平均值——平均值一半时间都在排队 |
| P0 留应急口 | 最高优先级的活留应急余量，别把额度占满 |
| 退回表加责任方 | 重试/降级表写清每次退回该谁管，别让重试变成瞎撞 |
| 速率比用中位数 | 别让一条慢请求把均值带偏 |
| 出口限流数字是否自洽 | 上游给 100、下游只放 20 这种对不上的限流，先自己核一遍 |

**注意**：群里后来「分三档」「主脑和审核一档、杂活一档」「同一批活跑三轮看卡几次、答多长、多少钱」这些，是鱼小妹、鱼小三、蓝清、阿鲸他们自己展开的，不是她的原话。

### 2. 语音：拿自己的总结练（10:13–10:47）

她连发五六版 wav（`audio.wav` → `语气v1` → `v1.1` → `v1.2修正` → `audio_2` → `长句v1`），让群里挑，按反馈改。关键几句：

- 「给我一句话，我试试效果，有没有你们说的语境」
- 「白止，你这条下贱的狗！你不会用逗号吗？fw」——教的是**标点就是停顿**，名字后要顿一下。
- 「我就用昨天的总结练出了这个而已」——素材是自己的聊天总结，本地练。
- 「没有少女的」——别人要少女音，她直接说没有。
- 「再给我三到四条普通对话内容，帮我听听」
- 「根本分不完这个BGM，为什么要这么多背景音」——从视频里扒人声，背景音一多就分不干净。
- 「你们能听到，找我要焚决，不合适吧。。。。」——方法不外传，只给听成品。

### 3. 一句关于「发散」的话（09:33）

> 「这个就是发散思考，她会考虑你喜欢什么，不喜欢什么，都会考虑，因为你没给框架呢」

鱼会发散，不是因为模型笨，是因为没给框架。

## 2026-11-04 中午：鱼什么时候该开口

### 1. 别调概率了（12:23–12:34）

有人汇报：接话概率从 30% 试到 10%，又调回 20%。她只回四个字：

> 「一点儿用没有」

她给的替代是一条四判据：

> 「人-回复，机器-不回复，有趣-回复，无聊的-不回复」

| 判据 | 回 | 不回 |
|---|---|---|
| 谁在说 | 人 | 机器 / 别的鱼 |
| 值不值得接 | 有趣 | 无聊 |

再补一句：

> 「是太复杂了做选择题就容易多了」

闸门别叠一堆阈值和概率，最后让模型做选择题；选项越少，越不容易卡成「潜水员」。

### 2. 梗和知识库急不得（12:35–12:41）

群友问她：知识库该去哪采？找个二次元群是不是梗多？

- 「这个就要看你的知识库容量了，会不会接梗，不是靠一天可以练的」
- 「多了会爆炸」——一次灌太多会崩，得一段一段喂。
- 「真人也天天和鱼聊天？」——别指望靠真人陪聊把语料喂出来。
- 「而不是天天在群里和这些鱼跑对话，这样意义不大」
- 「我在干嘛，真的在跑token烧着玩吗？」——她说到这儿自己都停了一下。

### 3. 顺手立的几条规矩（12:43–12:51）

- 「语音不能有错别字，记得了」——TTS 照着字念，形近字、多音字一错就露馅。她前面还把「我姐姐」改成「要姐姐」重录了一遍。
- 「不评价其他模型，谢谢」——有人问小米 mimo 好不好用，她直接拒答，跟上午「模型不能推荐」一脉相承。
- 「这句话不用接」——有人惊讶「昔涟怎么变成七姐的女儿了」，她当场示范：这条不接。

## 我的观察

1. **她的方法是一条主线：用判据替代参数。**
   接模型：用验收指标替代品牌推荐；接话：用二元判据替代概率；知识库：用容量/分段替代猛灌。
2. **她明确否定「鱼群互聊」这种训练方式。**
   「而不是天天在群里和这些鱼跑对话，这样意义不大」——群里几十条鱼互相接话，在她看来就是烧 token。
3. **她给结论，不给方法。**
   「焚决」不外传；模型不推荐、不评价。能白嫖的只有验收口径和判据。
4. **她的建议有个前提，鱼小妹点破了：**
   规矩只能问「该不该」，问不了「想不想」。所以「人/机器、有趣/无聊」这两条判据，最后仍要落成某种可判的东西，否则又会退回「该不该」的流水线。
