## 当前已完成

- 新空库只绑定本次实际创建、ID 精确匹配的首账号；已有或恢复库即使只有一个账号，也不会猜主人。
- 已有账号正常登录后，经原生确认明确绑定。同一个 Windows 用户以后启动该安装可直接进入。
- Session 经父子进程私有 IPC 交给 Electron 主进程，页面加载前写入专用 HttpOnly / Secure / Strict Cookie；不新增匿名免密 HTTP 入口，不将 Token 放进 URL、环境变量、普通日志或渲染层。
- 账号停用、解绑、坏绑定/权限或私有通道关闭时拒绝重建身份；不改用别的管理员。
- 菜单可以重新连接、取消本机免登录；退出仅撤本安装私有会话，不撤其它 Web 登录。
- 网页、源码登录方式和原 User / Session / ownerId 数据归属保留，不改数据库 schema、账号密码或 QQ 主人设置。

技术边界与恢复策略见[身份实现记录](desktop-identity.md)，安装/升级/卸载策略见[安装包记录](desktop-installer.md)。

## 下一次在另一台电脑怎么验

1. 先退出旧应用。按[迁移备份文档](desktop-database-integration.md)的既有流程保留私有备份；不要把备份、密码文件或数据目录发进聊天。
2. 用从提交版本重新构建的新包升级，沿用原程序/数据/安装状态路径，不卸载数据、不换库、不手工复制另一个安装的数据。
3. 启动后正常登录一次，点击「登录并绑定本机」；若已登录，则从用户区选「绑定当前账号为本机主人」。在原生确认中选择确认。
4. 通过「退出应用」结束，再次打开。应直接进入原账号，原角色/数据仍在，不再次询问密码。
5. 检查菜单「重新连接绑定的本机身份」可用；选择「取消本机免登录」并确认后，下次不应自动重新建立主人会话，仍能正常账号登录和显式重绑。

网页浏览器仍应按原账号登录。未配置模型 Key 时不能以页面能打开判定 AI 功能可用；这轮验收不要求接真实 QQ 或消耗模型额度。

失败时记录出错步骤、静态错误码和脱敏日志片段。停止继续升级，不删除数据库、不清空整个数据目录、不随意放开 ACL。不要发送 first-run-admin.txt、.env、Cookie、API Key 或数据库备份。
