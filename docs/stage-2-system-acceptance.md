# 阶段 2：全系统整合验收

验收基线：`main`，`bb4549c`；本轮包含下述两处修复。验收使用一次性 PostgreSQL、回环 HTTP 与合成消息；正式账户和数据仅作聚合只读观察。

| 验收问题 | 实际证据 | 结论 |
| --- | --- | --- |
| 群聊、私聊、网页是否共享该共享的资料 | 同一合成角色的三个入口向模型提供同一条正式知识。原教学私聊用同一句问题能召回自己的私人记忆；群聊、其他联系人私聊及角色主人的网页对话都没有该私记忆、教学原文或其来源引用。私聊连续两轮还验证了自己的上文可见、当前消息不重复、另一身份隔离。 | 通过隔离验证。群聊本例由语境助手请求查知识；不代表禁用语境助手或任意问法都能触发同样的检索。 |
| 私聊教学能否形成安全的全局表达 | 实际 OneBot 私聊写入两条教学相关消息；以已通过语义审核的合成经验作为夹具，实际教育 Worker 生成 `PENDING`；主人通过 HTTP 接口采纳、停用。同角色三个入口共九轮验证，只有 `ACTIVE` 时模型请求包含抽象习惯，回执采用对应表达。原教学私聊另作一次检索阳性对照。 | 通过跨入口工程验收。经验提炼没有在本用例重复验证，由独立成长闭环回归覆盖。 |
| 经验、反思、成长事件如何形成与隔离 | 自动经验 Worker 把跨日反馈提炼并独立语义审核，反思排程防重并生成待审表达；审核后仅在原会话生效，源经验停用后撤出。独立成长事件测试覆盖并发、租约、失败重试和来源变化下的候选失效。 | 通过隔离验证。私聊反思和授权教育迁移是两条路径；私聊反思不会自动转成全局表达或偏好。 |
| 记忆、知识、经验是否重复、冲突或错归属 | 验证同源经验不重跑、忆泡按范围与会话判重、不同事项保留、知识冲突保留双方及显式合并来源链、跨角色操作拒绝。另修复持久会话归属和知识有效成员计数，见下文。 | 通过已覆盖的确定性场景；不代表能识别所有语义重复、冲突或错误归因。 |
| 修改、删除、审核后是否更新 | 偏好、表达、目标、经验、认知和关系读取使用当前状态；知识归档或进回收站后退出检索，恢复后重新参与。待处理知识候选在来源归档、删除或转私人时失效。已采纳且应独立保留的规则与知识不因来源删除一律撤回。 | 通过隔离验证。全局偏好需要独立确认，私聊材料不会自动生成全局偏好。 |
| 下一轮是否体现变化 | 三入口模拟模型依据请求里是否有习惯返回不同回复。另用配置的 DeepSeek 文本模型和同一合成问题做三次对照：无习惯 → 提供习惯 → 移除习惯，仅中间一轮用了指定的「结论先行：」开头。 | 验证了实际请求到用户可见回复的变化，并有一次真实模型合成对照；没有把该对照当成真实群聊、长期学习或普遍语义质量已经通过。 |

## 修复并复验

- 知识主题列表只统计同角色、当前活动的知识；归档后计数立即减少，详情保留历史引用并标明失效，取消归档后计数恢复。知识版本变化不单独导致失效。实际 HTTP 回归覆盖完整过程。
- 会话迁到新记忆范围时，优先按忆泡的持久会话归属迁移。原文已删除仍能迁移；缺少会话归属的旧记录才从现存来源消息确认。隔离数据库验证在所有原文已删除时仍能移动正确忆泡，同范围的其他会话不被误搬。

## 执行与边界

- 通过完整本地 API 冒烟（其中包含新增的教育迁移三入口对照）、协作和私聊历史隔离、反思、教育迁移及旧证据、表达习惯、偏好、互动指导和成长范围边界回归；知识主题、知识版本/治理/生命周期、忆泡去重与记忆可靠性隔离回归也通过。成长事件中心独立数据库 runner 通过。隔离库应用 87 个迁移。项目类型检查、生产构建、改动文件 ESLint、隐私门禁和差异格式检查通过。
- 真实模型对照只发送合成问题、人设和习惯，不使用业务会话、记忆、人设或知识正文，也没有写入业务库或向真实 QQ 群发送消息。模型请求使用既有配置的端点和凭据，未输出凭据。
- 2026-11-19 11:34（上海时间）只读基线：本机开发入口可访问，OneBot 已连接；唯一活动角色未开启互动经验自动整理，最近 24 小时没有记录到当前源码 v76 的回复，也没有新的经验或反思样本。探针未看到过期经验/反思租约或看门狗告警。这些计数不能推断运行进程加载了哪个版本，也不能评价自然聊天质量。
- 自然使用验收还需在用户本来就要调整的前提下启用「互动经验 → 开启自动整理」，等待有依据的反馈和主人实际审核，再核对下一次相关回复。没有为验收打开业务开关或审核真实候选。自然使用中的错误归因风险仍按[实际使用验收](real-use-acceptance.md)跟踪。
