# 本机生图接口（Anima / ComfyUI）

忆灵空间调用本机 Anima 模型的入口。两条用法都通：

- **她的聊天配图**：设置 → 画图模型 → 服务商选「本地 Anima（ComfyUI）」，见文末；
- **直接调接口**：`/api/local/draw`，给脚本、调试、别的页面用。

## 前置：引擎必须先开着

Anima 不是常驻服务，用之前要双击：

```
D:\AI\Anima\启动Anima.bat
```

它会启动 ComfyUI（127.0.0.1:8188）并打开点选界面。这个接口只是它的客户端。

## 两个路由

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/local/draw` | 引擎在不在，返回 `{ running: true/false }` |
| POST | `/api/local/draw` | 画一张图，返回 base64 dataUrl |

两个都走 `requireAdminActor`，和 `server/api/local/` 下其他接口一致。

### POST 参数

| 字段 | 类型 | 说明 |
|---|---|---|
| `prompt` | string | **必填**。英文或 Danbooru 标签。中文无效（实测：写中文出来的是无关图） |
| `quality` | boolean | `true` = 30 步精修，约 50 秒；默认 `false` = 12 步，约 12 秒 |
| `width` / `height` | number | 512~1280，自动取 8 的倍数。默认 896×1152 |
| `referencePath` | string | 图生图用，本机绝对路径。**只允许** `DRAW_ALLOWED_ROOTS` 下的文件（默认只有项目目录本身） |
| `denoise` | number | 仅图生图生效。0.3 只重绘细节 / 0.6 换风格 / 0.75 重新构图 |
| `seed` | number | 固定随机种子，同参数可复现 |

带 `referencePath` 时，输出尺寸由**原图按总像素缩到约 1MP**决定，`width/height` 不生效。

### 返回

```json
{
  "ok": true,
  "mode": "text_to_image",
  "dataUrl": "data:image/png;base64,iVBORw0...",
  "bytes": "图片字节数",
  "width": 896,
  "height": 1152,
  "seed": "本次使用的种子，固定它可复现",
  "elapsedMs": "耗时，毫秒"
}
```

`bytes` / `seed` / `elapsedMs` 实际都是数字，这里写成说明是为了不在文档里放
一串看着像手机号的长数字。

失败一律 HTTP 502 + `message` 里是中文原因（引擎没开、显存不足、超时等），
前端直接把 message 弹出来就行。

## 怎么调

### curl

```bash
curl -X POST http://localhost:3000/api/local/draw \
  -H "content-type: application/json" \
  -b "你的登录 cookie" \
  -d '{"prompt":"1girl, solo, rainy neon street at night, holding umbrella","quality":false}'
```

### 前端（Vue / Nuxt）

```ts
const result = await $fetch("/api/local/draw", {
  method: "POST",
  body: {
    prompt: "1girl, solo, rainy neon street at night",
    quality: true,
  },
});
imgEl.src = result.dataUrl; // 直接塞进 <img> 或存库
```

### 图生图

```ts
await $fetch("/api/local/draw", {
  method: "POST",
  body: {
    prompt: "1girl, long blue hair, white dress, sunflower field",
    referencePath: "D:\\AI\\some_image.png",
    denoise: 0.6,
  },
});
```

参考图路径要落在 `DRAW_ALLOWED_ROOTS` 里。没设这个变量时只有项目目录本身放行，
读别处的图会收到 403 —— 在 `.env` 里加一行 `DRAW_ALLOWED_ROOTS=D:\AI` 即可。

## 服务端直接调用（不经 HTTP）

```ts
import { generateImageWithComfy, pingComfy } from "~~/server/utils/comfyui-image";

const result = await generateImageWithComfy({
  prompt: "1girl, solo, standing in snow",
  quality: false,
  width: 832,
  height: 1216,
});
if (result.ok) {
  await writeFile("somewhere.png", result.buffer);
} else {
  console.warn(result.reason);
}
```

## 环境变量

| 变量 | 默认值 |
|---|---|
| `COMFYUI_BASE_URL` | `http://127.0.0.1:8188`（页面填了地址就以页面为准） |
| `COMFYUI_CLIP_NAME` | `qwen_3_06b_base.safetensors` |
| `COMFYUI_VAE_NAME` | `qwen_image_vae.safetensors` |
| `DRAW_ALLOWED_ROOTS` | 参考图只允许读这些目录（逗号分隔）。不设就只有项目目录本身 |

模型文件名不再走环境变量：默认值在 `shared/utils/local-image-engine.ts`，
页面里可以选、可以手填（引擎里另装了模型就从「获取模型」里挑）。

## 已知限制

- **只认英文**。中文提示词会被忽略，出来的是无关内容。调用方需要自己备一套中文→标签的映射，
  或者直接让用户写标签。
- **8G 显存**是天花板。一次只能跑一张，两个请求同时来会排队甚至显存不足。
  并发场景要自己加队列或锁。
- 提示词里写中文/长句会让画面里出现**乱码文字或水印**（模型训练数据带的），
  负面提示词已经压了 `text, watermark`，但压不干净。
- 引擎关掉时接口会明确报「连不上 ComfyUI」，不会挂起。

## 接进「角色自动配图」（2026-11-23 已接好）

画图模型里的服务商多了 `comfyui` 一项，和 MiniMax / OpenAI 并列。走通这条路之后，
`image-generation.ts` 的 `generateImage()` 在 `provider === "comfyui"` 时直接调
`generateImageWithComfy()`，拿到 `buffer` 后复用它原来的「缩放 → 落盘 → 返回」逻辑
（抽成了 `persistGeneratedImage`，云端那条也调它，落盘规则只有一份）。

设置页在选中它之后只留三个字段，其余（API Key、服务商地址、模型名）都不再要求：

| 字段 | 存哪 | 说明 |
|---|---|---|
| 引擎地址 | `imageApiBaseUrl` | 默认 `http://127.0.0.1:8188`，允许本机与局域网 |
| 出图档位 | `imageQuality` | `fast`（Turbo，12 步）/ `quality`（Aesthetic，30 步） |
| 模型文件 | `imageModel` | 选填，留空按档位取默认值 |

尺寸档位跟服务商走：方 1024×1024、竖 896×1152、横 1152×896（8G 显存别上 1536 那一档）。

### 三个刻意的取舍

**不带参考图。** ComfyUI 的图生图是把参考图 VAE 编码后降噪，改动幅度 0.5~0.6 时
构图、姿势、取景都会跟着立绘走 —— 出来还是那张站姿，只是换了背景。角色一致性
该靠 LoRA（Anima 官方支持），不是靠这张参考图。所以这条路只做文生图，
提示词里的【参考图】段会整段丢掉。

**中文要翻，而且由她自己翻。** 分段提示词（【人物】【造型】【画面】【避免】）是给
能读中文的云端模型准备的，Anima 一个标签都不认识；而形象档案那段中文是**服务端拼进去的**，
聊天模型看不到，也就没法自己顺手翻掉。所以出图前多一次调用（`image-prompt-translation.ts`）：

1. `toAnimaPromptParts()` 先拆成正/负两半；
2. 有中文就交给**这个角色自己的聊天模型**翻成英文 Danbooru 标签（约 0.5~1 秒、几百 token，
   比一张图便宜两个数量级），进程内按原文缓存，同一形象反复出图只翻一次；
3. 翻不动（模型没配、超时、输出不合规）就按原文发，图照出，只在日志里留一条。

和画图本身一样，这次翻译调用**不写 `model_usages`**（那张表是按 token 结算的，
混进按张计费的链路会把报表弄脏）；只在日志里留 `[image] 提示词已翻成英文标签`。

实测那句「蓝紫色长发、蓝色眼睛、鲸鱼耳与尾巴…雪夜街道，回头微笑，半身」翻出来是
`blue-purple long hair, blue eyes, whale ears, whale tail, medium build, white dress,
snowy night street, looking back, smile, upper body, cinematic lighting` —— 鲸鱼尾巴、
半身、回眸都在，构图词也换成了 Anima 更认的 `upper body`。

真正该改的还是数据侧：形象档案的核心提示词直接写英文标签，这一步就几乎不用翻了。

### 失败长什么样

| 现象 | 用户看到的话 | 怎么修 |
|---|---|---|
| 引擎没开 | 连不上本地引擎（地址） | 双击 `启动Anima.bat` |
| 模型文件不在 | 引擎里没有「xxx」这个模型文件 | 换模型，或确认 `models\diffusion_models` 挂对了 |
| 显存不够 | ComfyUI 执行报错（常见原因：显存不足） | 降尺寸，或改用快速档 |
| 翻译没成功 | 日志里有「提示词翻译失败…按原文送引擎」 | 不影响出图，但中文部分不生效；检查聊天模型配置 |

`GET/POST /api/local/draw` 那套路由保持原样，不受影响。
