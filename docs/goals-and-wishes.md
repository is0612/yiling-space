# 目标与愿望

第一批管理角色自己想做的事，以及人确认过的进展。入口为成长系统“目标与愿望”，以现有Character身份隔离。

## 模型与边界

- `CharacterGoal` 当前目标，类型GOAL（较具体的方向）或WISH（尚未形成计划的愿望）；标题1–100字、描述和形成原因各1–1000字。
- `CharacterGoalRevision` 每次操作后完整版本快照，包含CREATE/EDIT/ACTIVATE/PAUSE/COMPLETE/ABANDON/REJECT/PROGRESS，与USER审计同事务写入。无变化编辑不产生空版本。
- `CharacterGoalProgress` 不可变追加进展，保存正文、公开来源快照和请求编号。追加进展会增加目标版本，但不会自行改变状态。

不把别人的愿望算成角色目标，也不把一次兴趣推断成承诺。第一批不做复杂任务拆解、提醒、定时任务、积分打卡、目标自动执行或主动找话联动。目标也不自动修改人设、关系或正式知识。

## 来源与确认

手工添加默认PENDING，用户可明确选择立即进行中；由来源添加必须PENDING。来源最多5条，复用已有公开Gateway：当前角色全局ACTIVE忆泡或当前角色ACCEPTED反思建议。创建候选与首次确认都会在事务内校验来源指纹、状态与角色，拒绝私人、跨角色、隐藏、删除或已修改的来源。已接受目标独立保留，原来源删除不删除它，暂停后恢复不重做首次来源审核。

用户可明确点击模型建议，使用当前角色聊天模型、每日额度与最多5条公开摘要，最多60秒，不在模型请求期间持数据库锁，返回后再验来源。输出严格限定kind/title/description/reason，也可返回null表示证据不足；只填可编辑草稿，不直接创建、接受、推进或完成目标。用量记为other，metadata.source=goal-suggestion。没有真实模型调用验证时不能声称语义效果已通过。

## 生命周期

| 起点 | 操作 | 结果 |
| --- | --- | --- |
| PENDING | 确认 | ACTIVE，重新校验来源 |
| PENDING | 驳回 | REJECTED |
| ACTIVE | 暂停 | PAUSED |
| PAUSED | 恢复 | ACTIVE |
| ACTIVE / PAUSED | 完成 | COMPLETED |
| ACTIVE / PAUSED | 放弃 | ABANDONED |

EDIT仅可修改PENDING/ACTIVE/PAUSED，不能夹带状态变更。COMPLETED/ABANDONED/REJECTED为终态，只能查看，首批不提供重新开启、删除或版本恢复。状态和编辑操作都携带expectedRevision，过期表单返回409。重要状态变化在页面有明确确认。

## 追加进展

只可为ACTIVE或PAUSED目标追加1–1000字正文。服务端可附带0–5条公开来源，写入时重新校验；首批页面提供人工文本追加，已有带来源进展会展示保存的快照。

同一目标内requestKey唯一。服务器在角色拥有者校验、目标行锁之后先查询旧请求：同key同规范化内容/来源返回原进展，不重复增加版本；同key不同内容409。expectedRevision是传输并发条件，不参与正文指纹。目标后来完成、暂停或版本变化，也不妨碍重放已经成功的同一操作。新的进展仍必须通过当前状态与版本校验。进展、版本和审计一起提交或一起回滚。

页面保留同一份草稿的请求编号与初始版本用于失败重试；修改正文后使用新编号。角色切换、关闭弹窗及在途旧请求不会覆盖新界面。

## 对话召回

桌面对话API及QQ链路只读取当前角色ACTIVE目标，按标题和描述做词法相关性排序，不额外调用模型。数据库候选最多100条，注入最多4条，序列化字符预算1000；描述截400字，最新进展截200字，并保留进展时间。PENDING、PAUSED及终态不会自动召回；历史查询扩展以后独立推进。

提示词版本conversation-retrieval-v56明确：想做不等于已做，不能声称聊天本身完成了目标、保存进展、设置提醒或执行外部动作，也不能强迫用户承担角色目标。模型返回usedGoalIds只认本轮白名单，沉默轮清空。桌面对话保存usedSources.goals，QQ保存usedGoalIds/usedGoals，历史读取保留当时版本和进展快照。引用是模型自报，不是已证明的行为因果。

词法匹配会漏近义表达；这里只提供一条最新进展，不等于完整项目计划。已有偏好和表达习惯仍分别管理。角色卡携带暂未接入，完整数据库备份可保留目标与历史。

## 验证入口

- `yarn test:goals`：输入白名单、终态、进展输入、召回预算、最新进展、引用白名单、历史回读和沉默轮。
- `yarn test:goals-page`：16组真实SFC脚本harness，覆盖角色ABA、表单来源、终态限制、请求竞态和进展重试key；不是DOM点击测试。
- `yarn test:goals-isolated`：只允许本机随机一次性库，执行全部73个迁移，覆盖状态/版本/审计、来源与角色边界、并发进展只写一次、终态幂等重放、不同payload冲突、进展与暂停竞争、分页及模拟模型请求安全；临时库最终删除。

本轮Prisma validate/generate、完整typecheck、目标纯逻辑与模拟模型引用测试、16组页面脚本、表达习惯/偏好/聊天回复回归、75个SFC编译、全量lint（0error/0warning）、OpenAPI YAML解析和生产build通过。隔离数据库73个迁移与业务场景已实际通过并清除临时库；另用审计INSERT故障验证进展/版本/历史全部回滚。构建仍有既有媒体下载BigInt目标环境警告和Vite耗时提示。
